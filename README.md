# 🔐 Secure Password Generator & Entropy Analyzer

Консольная утилита на Python для генерации криптографически стойких паролей и их математического анализа с точки зрения теории информации.

## 🚀 Возможности
- **Генерация:** Создание случайных паролей с использованием криптографически безопасного модуля `secrets`.
- **Анализ энтропии:** Расчёт информационной энтропии Шеннона ($H = L \cdot \log_2(N)$) для оценки непредсказуемости пароля.
- **Оценка брутфорса:** Перевод математических бит энтропии в понятное время взлома для гипотетического атакующего (при скорости $10^{10}$ попыток в секунду).
- **Динамический анализ:** Автоматическое определение реальной мощности алфавита ($N$) в зависимости от символов, использованных в пароле.

---

## 📂 Структура проекта
- `main.py` — интерактивная точка входа (меню пользователя).
- `generator.py` — логика генерации безопасных паролей.
- `analyzer.py` — математический модуль расчёта энтропии и времени взлома.
