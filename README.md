# 🔐 Secure Password & Pattern Generator + Entropy Analyzer

Утилита на Python для криптографически стойкой генерации паролей и графических ключей (Pattern Lock), а также математического анализа паролей с точки зрения теории информации.

## 🚀 Возможности
- **Генерация паролей:** Создание случайных паролей с использованием криптографически безопасного модуля `secrets`.
- **Генерация графических ключей (Pattern Lock):** Построение валидных последовательностей на сетке $3\times3$ с учётом правил промежуточных точек (`SKIP_RULES`) и визуализацией схемы в PNG через библиотеку `Pillow` (`PIL`).
- **Анализ энтропии:** Расчёт информационной энтропии Шеннона ($H = L \cdot \log_2(N)$) для оценки непредсказуемости пароля.
- **Оценка брутфорса:** Перевод математических бит энтропии в понятное время взлома для гипотетического атакующего (при скорости $10^{10}$ попыток в секунду).
- **Динамический анализ:** Автоматическое определение реальной мощности алфавита ($N$) в зависимости от символов, использованных в пароле.

## 📂 Структура проекта
- `main.py` — интерактивная точка входа (меню пользователя).
- `generator.py` — логика генерации безопасных паролей.
- `analyzer.py` — математический модуль расчёта энтропии и времени взлома.
- `pattern_generator.py` — генератор и визуализатор графических ключей $3\times3$ (`PIL`).

## 💻 Как запустить

1. Убедитесь, что у вас установлен **Python 3.x**.
2. Клонируйте репозиторий:
   ```bash
   git clone [https://github.com/fmarichev33/SecurePasswordTool.git](https://github.com/fmarichev33/SecurePasswordTool.git)
   cd SecurePasswordTool
3. Установите зависимость для работы с изображениями (Pillow):
   ```bash
   pip install pillow
4. Запустите основной скрипт или генератор графических ключей:
5. ```bash
   python main.py
   # или для генерации схемы графического ключа:
   python pattern_generator.py
